# Portafolio personal — Santiago Perdomo Vargas

Portafolio web construido con Vite, React y TypeScript. Presenta intereses personales, tecnologías en aprendizaje y proyectos de clase.

## Iniciar el proyecto

1. Instala Node.js.
2. En la carpeta del proyecto, instala las dependencias:

   ```bash
   npm install
   ```

3. Inicia el servidor local:

   ```bash
   npm run dev
   ```

4. Abre en el navegador la dirección que indique Vite, normalmente `http://localhost:5173`.

## Estructura

- `src/App.tsx`: interfaz y componentes `Presentacion`, `ListaTecnologias`, `ListaProyectos` y `TarjetaProyecto`.
- `src/styles.css`: estilos adaptables para celular y computadora.
- `index.html`: idioma, título y descripción de la página.

Las tecnologías y los proyectos se guardan en arreglos y se muestran con `map`. Para editar tus textos, tecnologías o proyectos, cambia los datos en `src/App.tsx`.

## Proyectos incluidos

- **Fila creativa:** ejercicio de React para organizar turnos por orden de llegada (FIFO).
- **Estante Compartido:** catálogo web de libros conectado a una API.
